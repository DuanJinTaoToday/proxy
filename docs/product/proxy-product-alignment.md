# B 端代理服务产品与一期目标对齐

本文记录项目讨论已达成的共识，以及需要老板推动的供应商事项。供产品范围和一期验收对齐使用。

与老板对齐时可使用[一期验收与联调简版](../features/proxy-phase-one/proxy-phase-one-brief.md)及[一期目标架构图](../diagrams/proxy-phase-one.png)。

## 产品形态

`proxy` 面向企业客户提供代理服务。客户以租户为单位获得代理接入权限、查询用量，后续由平台按租户出账。产品分为动态 IP 和静态 IP，动态 IP 提供隧道转发和 API 提取两种接入方式。

| 产品与接入方式 | 客户怎么用 | 供应商与一期范围 |
| --- | --- | --- |
| 动态 IP · 隧道转发 | 使用平台发放的代理凭据连接 `proxy-gateway`，由网关经悟空转发到目标。 | 悟空已在我方服务器部署隧道接入。一期走通真实转发、流量上报和用量展示。 |
| 动态 IP · API 提取 | 调用 `proxy-control` 提供的统一提取 API。`proxy-control` 向悟空提取并返回 `IP_List`，客户随后直连列表中的 SOCKS5 入口，业务流量绕过 `proxy-gateway`。悟空计量这部分流量，`proxy-control` 按租户拉取并汇集到平台。 | 老板正在推动悟空部署提取服务。一期先 Mock 提取与用量查询，部署后联调真实接口。 |
| 静态 IP | 平台将固定代理资源分配给租户。实际接入方式、到期和续期承诺待确认。 | 由[皇冠](http://www.ipcrown.com/buy-center?mid=132)供应。按当前业务信息，这批资源可零成本持有，适用条件待确认。一期完成资源、分配、交付与到期的领域建模，实际库存同步、自动开通和续期留待后续。 |

悟空目前是唯一的动态 IP 供应商。后续接入其他供应商时，由适配层处理上游地址、认证、接口格式和用量数据差异。按实际能力划分隧道接入、API 提取、上游用量查询和静态资源管理，供应商只接入其具备的能力。产品定义、租户归属和计费规则由平台掌握。

## 一期交付与验收

隧道流量以 `proxy-gateway` 上原版 GOST Recorder 的客户端侧计数为准。成功建立的代理会话可包含 SOCKS5 协议字节，失败连接不计用量。平台按租户汇总上行和下行，合计为两者之和。若悟空能提供同期用量，可用于核对统计口径。采集和恢复方案见[一期 Spec](../features/proxy-phase-one/proxy-phase-one-spec.md)。

| 验收项 | 可观察结果 |
| --- | --- |
| 真实隧道与流量上报 | 两个测试租户各用自己的平台凭据，通过 `proxy-gateway` 和悟空隧道访问目标。产生的上行、下行流量上报后分别归属正确的租户。 |
| 租户自查 | 租户成员在控制台选择日期范围，默认按天查看本租户的上行、下行和合计，并能看到数据更新到什么时候。两个测试租户均只能看到各自的数据。 |
| 运营查询 | 授权运营人员可按租户和时间查询用量，并追查对应的上报记录。对同一租户和时间范围，运营与租户看到的汇总口径一致。 |
| API 提取 Mock | 租户通过平台 API 收到模拟 `IP_List`。平台能将模拟的悟空流量归到正确租户，和隧道用量按接入方式区分。真实列表的可用性、流量归属和统计口径在联调阶段验收。 |
| 静态 IP 与计费领域模型 | 说明静态资源如何归属、分配、交付和到期，说明三类计费各自依据哪些业务事实，以及客户应收与供应商成本如何区分。 |

一期交付用量展示、以计费字节计量的流量额度与准入拦截，以及静态 IP 领域建模。运营可为租户充值流量、配置上下行倍率和准入门槛。金额定价、套餐和优惠等运营规则，以及出账和结算，待计费口径确认后另行排期。

## 计费领域边界

平台先保留可追溯的用量或资源分配事实。隧道转发和 API 提取都按流量计费，分别采用网关计量和悟空计量。将来由平台的计价规则计算租户应收，供应商金额单独用于对账及核算采购成本。悟空如果只能提供共享账号总流量，需要先确定可用的租户隔离或归属方案，才能把提取流量纳入租户用量。

| 预期计费类型 | 依据的业务事实 | 待定规则 |
| --- | --- | --- |
| 隧道转发流量计费 | 网关上报的租户、网关实例、计量时间、上行和下行字节。一期按上下行倍率换算为计费字节并扣减流量授予，额度不足时拒绝新连接。 | 金额定价、套餐和超额收费规则。 |
| API 提取流量计费 | 悟空计量客户直连 SOCKS5 入口产生的流量，`proxy-control` 通过用量 API 获取并按租户汇集。 | 租户关联标识、查询时间粒度、流量统计范围和客户计价规则。 |
| 静态 IP 计费 | 资源与租户的分配关系、资源数量、分配和到期时间。 | 对客售价、租期、续期和提前失效的处理。皇冠资源的持有成本与对客售价分别核算。 |

提取请求数和返回条数可用于排查交付问题。API 提取的计费依据是代理实际使用的流量。

## 需要老板推动悟空提供的接口与数据

**一期真实隧道联调所需**

- 隧道入口、认证方式和连接样例见[悟空隧道接入记录](../integrations/wukong-socks5-tunnel.md)。按现有记录推进平台侧联调，若测试环境变化再向悟空确认。
- 如有隧道用量查询或导出能力，提供同期用量样例和统计口径，包括时间窗口、统计方向和字节范围。这项用于后续对账，一期展示以网关计量为准。

**API 提取真实接入所需，可与一期 Mock 并行推进**

| 请老板推动悟空提供 | 需要确认的内容 |
| --- | --- |
| 提取服务部署与联调环境 | 明确部署负责人和可联调时间，提供联调地址、测试凭据及认证方式。 |
| 提取 API 文档和请求、响应样例 | 覆盖成功、部分成功、失败和超时后重试。说明 `IP_List` 每条记录的连接地址、端口、认证方式、有效期，以及重试是否可能重复提取。 |
| 流量查询 API 文档与响应样例 | 确认返回区间增量还是累计值、时间窗口和时区、单位、是否区分上下行、数据更新延迟及补记或更正规则。 |
| 流量与租户的关联方式 | 确认能否通过上游子账号、独立凭据或客户标识区分租户，以及提取和用量查询两端如何使用这个标识。请提供两个租户各自提取、直连并查询用量的样例，同时确认查询范围能否区分 API 提取和隧道流量。 |

老板对齐时请确认一期交付和验收边界，并明确悟空提取服务的对接人与联调时间。皇冠资源的零成本适用条件、供货和续期规则，留待静态 IP 产品准备交付时核实。
