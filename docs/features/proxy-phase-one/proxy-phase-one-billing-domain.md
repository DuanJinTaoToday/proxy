# 一期静态 IP 和流量计费领域模型

关联 [Issue #12](https://github.com/DuanJinTaoToday/proxy/issues/12)、[一期 Spec](proxy-phase-one-spec.md)和[产品对齐](../../product/proxy-product-alignment.md)。

租户是客户侧的归属主体。动态 IP 记录实际用量，静态 IP 记录资源分配及其有效期。后续客户应收以这些事实和平台的计价规则为依据。供应商成本按采购合同及供应商结算资料核算，可以回溯对应资源或用量；能否分摊到具体租户取决于供应商数据和成本分摊规则。

## 同一租户的三类事实

以下数值与标识仅用于说明模型。假设租户 A 同时使用悟空隧道、悟空 API 提取和皇冠静态 IP。

| 业务 | 事实与租户归属 | 后续客户应收依据 | 供应商成本依据 |
| --- | --- | --- | --- |
| 悟空隧道 | 网关为已建立的会话记录一次上行 100、下行 900 字节的 Recorder 增量。控制面通过凭据的稳定 `client_id` 找到租户 A，以 `tunnel` 来源按记录时间归集。 | 隧道计量和适用的对客计价规则。 | 悟空合同和结算资料；网关字节量可用于对账，金额由采购口径确定。 |
| 悟空 API 提取后直连 | 租户 A 从平台取得 `IP_List`，随后直连其中的 SOCKS5 入口。假设悟空返回某时间窗内可明确归属于 A 的 2,000 字节直连流量，控制面可按供应商租户标识映射到 A，以独立来源归集。 | 已确认归属且与隧道口径分离的供应商直连流量，以及适用的对客计价规则。 | 悟空合同及对应的用量或结算明细；同一份可归属的计量可支持对账。 |
| 皇冠静态 IP | 平台将皇冠提供的资源 S1 分配给租户 A，分配记录关联供应商资源、租户及分配起止时间。示例分配自 11 月 13 日 10:00 起，到 12 月 13 日 10:00 到期，共一项资源。 | 分配记录、资源数量和适用租期，以及平台确认的对客计价条件。 | 皇冠采购和续期条款。若这项资源满足零成本持有条件，则该持有成本为零；对客售价独立确定。 |

隧道按合格 Recorder 记录的增量计量。周期记录与结束记录各自只贡献本条增量，重放按网关实例、启动代次和文件定位文件水位，已整段确认的记录跳过。晚到记录按 `recorded_at` 选择当时生效的租户分组归属、计费倍率和流量授予。示例中，上、下行倍率均为 1 倍时，这条记录折算为 1,000 计费字节，按既有规则消耗授予，超出可用额度的部分记为字节欠费。历史凭据停用后仍可解析历史记录的租户。[ADR 0001](../../adr/0001-usage-data-model.md) · [ADR 0002](../../adr/0002-service-and-proxy-identity.md) · [ADR 0003](../../adr/0003-reporting-and-usage-contracts.md) · [ADR 0004](../../adr/0004-billing-ingestion-and-audit.md)

提取响应证明租户获得入口列表，实际字节量来自后续供应商计量。真实接入前需确认供应商标识能追溯到租户，并能从供应商用量中单独识别直连流量。只有共享账号总量或隧道与直连混合总量时，保留供应商侧数据用于核对，待可拆分并确认归属后再纳入租户直连用量。一期仅有独立的 `api_extraction_mock` 模拟来源，真实直连的额度扣减规则随供应商接入确定。[ADR 0004](../../adr/0004-billing-ingestion-and-audit.md#4-用量来源与归档后补报)

## 静态 IP 的分配、交付和到期

- **分配**记录平台将哪项皇冠资源在什么有效期内划归哪个租户。资源与分配分别标识，资源后续重新分配时保留原租户的历史记录。
- **交付**表示租户实际获得可用的接入信息和权限。分配之后可以仍待交付，例如 S1 已分给 A，但凭据尚未交付。记录交付结果可用于判断客户何时获得服务。
- **到期**表示本次分配的有效期结束。到期后保留原记录供追溯。对客接入何时停用、皇冠资源何时释放、是否可原 IP 续期及提前失效如何处理，随交付规则确认。

## 待定事项

| 事项 | 待确认 |
| --- | --- |
| 实际交付 | 皇冠库存如何确认、接入方式和凭据如何交付、如何确认可用、到期停用与资源回收、续期保号、提前失效和交付失败的处理。 |
| 定价 | 两种动态流量来源适用的对客价格，静态资源按数量和租期如何定价，以及计价何时起算、续期与提前失效如何计价。皇冠零成本持有的条件也待核实。 |
| 扣款 | 真实 API 提取流量是否共用隧道流量授予、何时扣减，以及客户应收何时从资金账户扣款、失败或退款如何记账。隧道一期已约定的扣减单位为计费字节。 |
| 出账 | 租户账期、出账时间、明细与调整规则，以及供应商对账周期和成本分摊规则。账务流水记录实际发生的资金变动，客户应收记录依计价规则算出的金额。 |
