# Proxy 首版商业交付 Spec

**状态：已发布** · [GitHub Spec #36](https://github.com/DuanJinTaoToday/proxy/issues/36)

本 Spec 取代[旧一期 Spec #1](https://github.com/DuanJinTaoToday/proxy/issues/1)。旧一期的实施票与验收记录可继续追溯。

首版交付动态住宅 GB 和静态住宅 IP。客户自助开户，运营手动为租户钱包充值，客户从钱包购买商品。动态住宅 GB 通过 SOCKS5 隧道接入，静态住宅 IP 由皇冠交付并支持到期前手动保号续费。两类商品独立验收、独立开售。

产品依据见[已确认的产品决策](../../product/proxy-first-release-decisions.md)，与现有实现的差异见[差异审计](../../product/proxy-first-release-gap-audit.md)。

## 注册与代理子账号

- 客户用中国大陆 `+86` 手机号和密码自助注册及登录，每个手机号只对应一个登录账号。带或不带 `+86` 的同一号码按同一个账号处理。首版暂不提供验证码、Google 登录。注册成功自动创建租户和唯一的控制台管理员，钱包与流量余额均从 0 开始。忘记登录密码时由运营核实租户归属后协助重置。
- 控制台登录密码至少 12 位，注册和重置均适用。
- 管理员按需创建代理子账号。首版每个租户固定最多 10 个，启用和禁用的账号均计入。子账号名在租户内唯一，为 4–8 位，以小写字母开头，剩余字符为小写字母或数字。密码由管理员设置，为 6–12 位英文字母和数字，两类字符都须包含。管理员可查看、修改密码，编辑备注及启用或禁用账号。账号名固定，历史用量保留。
- 子账号只用于动态隧道。使用 `<主账号名>.<子账号名>` 作为 SOCKS5 用户名，主账号名由平台分配且全局唯一。可追加 `-sid-<会话标识>` 和 `-sidtime-<时长>`。网关收到禁用或密码更新后，按新状态认证新连接，已有连接继续到正常结束并照常计量。当前 GOST 认证插件无法按账号主动断开已有连接。

## 动态住宅 GB

- 首版提供 SOCKS5 动态隧道和默认出口池。未来如开放 API 提取，两种接入共用租户流量余额，用量明细按接入方式展示。
- 不带会话后缀时使用子账号的默认会话。显式 `sid` 按子账号隔离，允许 1–32 位小写字母或数字。Proxy 管理上游 SID 映射，将同一会话的请求路由到同一个悟空入口，并将客户提供的 `sidtime` 透传给悟空。省略时省略上游时长后缀，使用悟空默认行为。实际会话时长、到期处理和出口 IP 由悟空决定，同一会话重连时出口 IP 可能变化。
- 新连接要求租户可用流量余额大于 0，且代理子账号已启用并满足累计用量上限。子账号可设累计用量上限，未设置时不受子账号用量限制。管理员可调高或取消上限，累计用量保留。达到子账号上限或租户余额耗尽时，已有连接照常计量，超出租户余额的用量记为负余额。新到账流量先抵扣负余额，符合准入条件时自动恢复接入。
- 首版默认 5 GB、50 GB、200 GB 三档，后两档每 GB 单价默认比 5 GB 档低 10% 和 20%。运营可调整各档配置，也可单独下架某档。下架后官网和控制台隐藏该档并停止接受新订单，历史订单仍可查询，已到账流量可继续使用。一笔订单购买一份套餐，提交订单成功后按锁定容量和价格成交。流量长期有效，用完为止。
- 具备计费管理权限的运营人员可调整套餐配置和上下架。系统记录操作人、操作时间及修改前后的值。
- 动态隧道按计量总字节数固定 1:1 扣减，产品长期采用统一口径。套餐、余额、累计上限、提醒、用量页和 CSV 统一采用 1 GB = 1,000,000,000 字节。
- 管理员设置低余额阈值。余额降到阈值或以下时在控制台提醒一次，回到阈值以上后可触发下一轮。用量页默认显示租户总用量，按天展示实际从租户流量余额扣减的流量及数据更新时间，可按日期和代理子账号筛选，已禁用账号仍可查历史用量。
- 用量页可按当前筛选条件导出 CSV，按天列出实际扣减流量。

## 钱包与订单

- 仅具备计费管理权限的运营人员可以手动为租户钱包充值。必填租户、金额和原因。提交前由操作人确认租户名、主账号名、充值金额及预计到账后余额。系统记录流水号、操作人、到账时间和变动前后余额。运营处理充值异常。
- 商品按标价从钱包结算，流量阶梯优惠包含在套餐售价中。钱包余额不足时提示差额，充值后由管理员重新确认并提交。首版只使用钱包，暂不接入外部支付渠道、在线充值及优惠券。
- 流量套餐的钱包扣款、流量入账和订单成功一起生效。到账流量先抵扣负余额，可用余额转正后，符合准入条件的子账号自动恢复接入。
- 「订单记录」统一展示流量包、静态 IP 购买和续费，可按类型和状态筛选，详情显示锁定价格、扣退款和实际到账流量或交付数量。「钱包流水」按时间展示充值、扣款和退款，显示变动金额和变动后余额，可跳转关联订单。静态 IP 订单退款退回租户钱包。
- 客户需要开票时联系运营，由运营在线下处理。
- 充值和售后由客户线下联系运营。运营后台支持按主账号名或注册手机号查找租户，并从租户详情查看钱包和订单。

## 静态住宅 IP

- 可售地区、IP 类型、租期、单价和可购量以皇冠为准。客户选择规格和数量，皇冠分配 IP。提交前复核价格和库存。价格变动时展示新单价和总价，库存不足时展示最新可购数量，由客户调整或确认后再提交。成功提交时锁价，按申请数量预扣。
- 已到手的 IP 可立即使用，按实际交付数量结算。确认无法交付的部分释放预扣或退款。下单满 24 小时无明确结果转运营，满 72 小时仍无法确认则由运营关闭剩余交付并退回相应金额。之后补发由运营处理，客户侧按退款前交付数量结清。
- 「我的 IP」显示每个 IP 的皇冠到期时间，到期前 5 天在控制台提醒一次并标记即将到期。支持单条复制及勾选可用 IP 导出 TXT，每行 `IP:端口:用户名:密码`。到期后仍可查看记录。
- 到期前可手动续费，支持单个和批量。批量统一选租期，提交时逐项锁定现价。成功后保留原 IP，从原到期时间顺延。明确失败的款项释放或退款，结果未知时先查单，同一 IP 暂停重复提交。若确认期间到期，先停止服务，确认保号续费成功后恢复。未在到期前提交续费的 IP 到期后需重新购买。自动续费留待后续。
- 续费提交满 24 小时仍无结果转运营，满 72 小时由运营关闭仍无法确认的订单并释放或退款。后续皇冠确认成功由运营处理。皇冠文档支持批量传入明细 ID，混合结果和保号行为待联调。如无法逐项确认，验证单 IP 串行续费及独立结算。 [皇冠续费接口](https://www.yuque.com/ludeng-4v9rr/egw6bz/lq4d0lxmbgb1izii#dR0Q9)

## 官网与控制台

- 游客可查两类商品报价，登录后回到原购买页，保留流量档位或静态 IP 的地区、类型、租期和数量。页面展示最新价格和库存，由管理员确认后提交。控制台默认打开「账户概览」，展示钱包余额、动态流量余额、静态 IP 数量与提醒，并提供购买流量、创建代理子账号、购买静态 IP 三个快捷入口。
- 「动态住宅代理」提供接入示例。选择已启用的子账号后，可查看和复制网关地址、端口及账密。
- 官网公开基础 SOCKS5 配置示例、用户名格式和用量说明，使用示例账号。实际网关地址和账号密码在登录后的控制台查看。
- 动态住宅 GB 和静态住宅 IP 可以分开开放购买，各自验收通过后再开售。
- 尚未开售的商品保留官网介绍，标记「暂未开放购买」。通过验收并开售后展示报价和购买入口。
- 两类商品各自维护开售状态。验收通过且报价就绪后，由具备计费管理权限的运营人员手动开启对应商品的购买入口。

## 技术约束

- GOST 文件 Recorder 是动态隧道计量来源。以服务身份上报，按稳定 clientID 归属租户和子账号。成功会话可含 SOCKS5 协议字节，失败连接不计量。扣减、汇总及水位同批提交，跨日按后一次采样的上海自然日归属，重放保留原记录时间且只扣一次。
- 区分钱包金额、动态流量余额和静态 IP 分配记录。订单、入账及退款需要能逐笔对账。客户和运营的用量基于同一份计量事实。首版上线前没有历史业务用量需要迁移。
- 保留网关认证状态过期、失败时拒绝新连接和恢复追平的工程约束。负余额涵盖已建立连接后续产生的实际用量。开售前确认客户端到网关的凭据传输保护。
- 网关进程重启时补报已写入文件的记录。退出前未写入的尾段仅标示可能缺口，缺失字节未知。采集、归档、回放、容量与持久化边界见[用量技术方案](../proxy-phase-one/proxy-phase-one-architecture.md)。

## 开售验收

| 验收范围 | 操作与预期 |
| --- | --- |
| 开户与权限 | 用带和不带 +86 的同一号码验证唯一性。开户即有唯一管理员和零余额；双租户不能互查用量、账密、钱包和订单。验证计费权限受控，代理子账号无法登录控制台。 |
| 钱包与商品 | 确认运营充值信息并核对流水。余额不足提示差额。重复提交或事务失败时核对无重复扣款、无部分到账。验证套餐修改、下架与已成交订单快照，以及两类商品开售开关独立生效。 |
| 动态接入与扣减 | 购买一份套餐，选择子账号复制配置并走真实悟空 SOCKS5。核对总字节 1:1，日用量、CSV 与流量扣减一致。验证同名子账号跨租户隔离，改密、禁用及累计上限对新旧连接的影响。余额到 0 或负数时新连接被拒，旧连接续计。充值先抵欠，转正并同步后恢复符合条件的接入。验证低余额提示仅在重新越过阈值后进入下一轮。 |
| 动态会话 | 验证默认会话及显式 SID 按子账号隔离，SID 格式非法时拒绝。对照控制台配置、网关和真实悟空，验证显式 sidtime 透传、省略时使用悟空默认行为，以及同一会话的新连接选择同一个悟空入口。验证入口不可用时的处理符合文档。客户文档与商务对接说明有限支持，实际时长、到期处理和出口 IP 由悟空决定。自定义入口验收通过前保持关闭，普通 SOCKS5 接入可独立验收开售。 |
| 静态购买 | 用皇冠真实订单验收报价、库存复核、锁价、分配、可用凭据和代理连接。核对逐 IP 到期时间、到期提醒、复制和 TXT。用受控场景验证部分交付立即可用、按实交结算、剩余款项退款及运营接手。 |
| 静态续费 | 用皇冠真实订单验证到期前续费后保留原 IP，并从原到期时间顺延。验收单个和批量，逐 IP 核对结果和资金。验证明确失败、确认中禁止重复提交及确认期间跨到期的停用和恢复。若批量接口无法逐项确认，验证单 IP 串行续费与独立结算。 |
| 技术回归 | 复跑跨日、入库确认丢失、重放去重、冷缓存和离线续期边界、GOST 异常退出及目标环境集中关闭容量。历史测试作为基线，首版验收记录实际版本、环境和结果。 |

供应商待核实项见[悟空隧道接入](../../integrations/wukong-socks5-tunnel.md)和[皇冠静态 IP 接入](../../integrations/ipcrown-static-ip.md)。旧环境与复跑记录见[历史验收索引](../proxy-phase-one/proxy-phase-one-development.md)。
