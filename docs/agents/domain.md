# Domain Docs

The three deployment units share one domain documentation context.

## Before exploring, read these

- Read the root `GLOSSARY.md` for shared domain terminology.
- Read the relevant decisions under the root `docs/adr/`.

If either location is missing, continue exploring. Use the `domain-modeling` skill to add entries as terminology and decisions are resolved.

## Use the glossary's vocabulary

Use the glossary's terms in issues, design discussions, and tests. If a needed term is missing, check how the project already names the concept and note any gap for `domain-modeling`.

## Flag ADR conflicts

If a proposal conflicts with an existing ADR, cite the ADR and explain which decision needs to be revisited.
