# 架构决策记录

本目录保存影响多个部署单元、难以撤回或需要说明取舍的架构决策。三个部署单元共用这里的决策，术语见[GLOSSARY](../../GLOSSARY.md)。

一期尚未决定的事项列在[一期技术方案的待定设计](../features/proxy-phase-one/proxy-phase-one-architecture.md#待定设计)。某项决定需要记录理由或备选方案时，在这里新增 ADR，并在技术方案中引用。只影响单个实现细节的结论直接写入对应文档。

## 编写约定

- 文件名采用 `NNNN-短标题.md`，编号从 `0001` 递增，不复用。
- 状态取 `提议`、`已采纳`、`已废弃` 或 `被 NNNN 取代`。已采纳的 ADR 不改写结论，改变决定时新增 ADR 并更新旧记录的状态。
- 提案与现有 ADR 冲突时，引用该 ADR，说明需要重新讨论的决定。

## 模板

```markdown
# NNNN 标题

状态：提议 · 日期：YYYY-MM-DD · 相关任务：Issue 链接

## 背景

需要决定的问题，以及约束条件。

## 决定

采用的方案。

## 备选方案

考虑过的其他方案及未采用的原因。

## 影响

对实现、运维、接口兼容和验收的影响，以及需要同步更新的文档。
```
